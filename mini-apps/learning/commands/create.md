quality checklist. Use preferences already given; ask together for missing preferences that change
the route. Do not ask about generation strategy: prepare one complete module at a time. Write a
compact outline JSON and use action draft with outline_path to create the pending hierarchy. Author

request later modules as the learner advances; inspect generation failures if the tutor wake does
not reach an agent. Keep long prose in Markdown.
