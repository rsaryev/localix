# team

A starter team of Claude Code agents: `architect`, `backend`, `frontend`, `design` and `devops`.
Each file says who the role is and what its report contains; how a turn hands work on is the
conversation protocol’s, stated once for every agent.

In Localix, find it in the Store (Recommended), install it, and use **Copy to Yours** on an agent to
edit a copy. In Claude Code: `claude plugin install team@localix`.
