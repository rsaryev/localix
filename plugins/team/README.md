# team

Starter specialist agents for Claude Code: `architect`, `backend`, `frontend`, `design` and
`devops`. Each file says who the role is and what its report contains. Start a chat with one, or
name it as the type of a subagent (`Agent` with `subagent_type`).

In Localix, find it in the Store (Recommended), install it, and use **Copy to Yours** on an agent to
edit a copy. In Claude Code: `claude plugin install team@localix`.
