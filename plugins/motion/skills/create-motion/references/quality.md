# Motion craft and references

For dark films, use a deliberate hook → reveal → resolve rhythm. Blackout starts with large masked
type on a measured stage; Relay hands that attention to an editable product flow; Nightfall uses
warm graphite and a slower aperture reveal. Keep one leading move and a readable hold. The grid is a
coordinate stage for the moving type, not workbench decoration. Use `grid` and `frame` layers when
those primitives serve the composition; keep their color and transforms editable.

Build a storyboard before animating. Pair each beat with its message, layout, entrance, hold and
exit. A viewer should understand the film without reading the creative brief. Start from a visual
hierarchy, then choreograph the reveal. Hold a headline long enough to read it; shorten setup beats,
not the important evidence. Keep a clear end card. Maintain continuity through position, color or
shape between scenes rather than applying the same transition everywhere.

For custom layers, prefer one leading movement per scene and a few restrained secondary moves. Use
`out` for decisive arrivals, `smooth` for balanced changes, `linear` for deliberate continuous
motion and `spring` sparingly for physical reveals. Avoid endless loops behind dense text. Test
portrait and square compositions independently: changing the aspect ratio alone is not art
direction.

The researched collection is in [REFERENCE.md](../../../REFERENCE.md). NullMotion demonstrates
breakdowns and synchronized drafts; the Remotion libraries supply inspectable scene and template
source. External code is inspiration and a source to inspect, not a dependency or permission to copy
media. Inspect each license and asset notice before reusing source or media. Local templates are
original canvas compositions with no redistributed external scenes or reference films.

## Different directions need different rhythm

A product film earns a confident reveal and a readable detail shot. A kinetic-type piece uses
masking, cuts and a few quick syllabic beats. An event poster can hold oversized type while a
rosette turns. Editorial work needs measured spacing, serif lettering and longer holds. Data motion
needs verified values in `series`, consistent scales and enough time to compare them. A brand film
can resolve interlocking geometric layers into a settled mark. These are choices, not a requirement
to put every technique into one film.

Use the guide's primitive layouts and complete keyframe preset examples as a vocabulary. The editor
exposes Pop, Glide, Pulse and Turn; adapt their timing to the message and maintain a final pose.
Scene palette overrides let a hard cut change register without repainting every scene. Anchor
connectors to actual nodes; use masks to reveal content. Keep all state seekable from scene time.

The official Remotion skills and HyperFrames creative/motion sources in REFERENCE.md were inspected
for authoring practices, rhythm, reusable blocks and deterministic timelines. Localix uses original
code and its own schema; these references are not installed runtimes or automatically loaded skills.
